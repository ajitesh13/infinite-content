# Generated visual catalog for Gītā verse matching

This catalog covers the 50 numbered JPGs in assets/background/ and the standalone PNG in assets/backgrounds/. The sample screenshots are excluded because they are app captures, not generated visual assets.

The **literal extract** records only what is visibly depicted. The **verse fit** fields are editorial candidates drawn from the draft reference in [content/bhagavad-gita-daily-life.md](../content/bhagavad-gita-daily-life.md); they are not claims that an image is an authoritative scene from the Gītā. Scripture, translation, theological context, image respectfulness, and rights still require human review before publication.
